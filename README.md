# Shooting Demo (UE5.4 + C++)

## 项目简介
基于 UE5.4 和 C++ 开发的第三人称射击 Demo，包含武器系统、敌人 AI、对象池、视角切换、UMG HUD。

## 核心功能
- **武器系统**：生成、拾取、挂载到右手骨骼、射线检测开火、全自动连发、弹药管理、换弹
- **敌人 AI**：状态机索敌、追击、攻击、死亡
- **对象池**：预创建敌人实例，循环复用，减少 GC 压力
- **玩家**：血量、受伤、死亡、闪现技能（带冷却）
- **视角**：第一人称/第三人称切换（V 键）
- **UI**：UMG 血条、弹药数、技能冷却、准星

## 技术栈
- UE 5.4
- C++（UPROPERTY、UFUNCTION、FTimerHandle、前置声明）
- 增强输入系统（Enhanced Input）
- UMG

## 操作方式
- WASD：移动
- 鼠标：视角
- 左键：开火（全自动）
- R：换弹
- E：拾取武器
- Q：闪现
- V：切换第一/第三人称
